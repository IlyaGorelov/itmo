# Лабораторная работа №5

## Описание

По выданному варианту необходимо разработать программу **асинхронного обмена данными с внешним устройством**.  
Программа должна осуществлять **ввод или вывод информации**, используя в качестве подтверждения передачи данных **сигнал готовности ВУ**.

## Вариант

**5467**

## Условие задания

1. Программа осуществляет **асинхронный ввод данных с ВУ-3**.
2. Программа начинается с адреса **456₁₆**. Размещаемая строка находится по адресу **550₁₆**.
3. Строка должна быть представлена в кодировке **КОИ-8**.
4. Формат представления строки в памяти:

| Адрес | Содержимое  |
| ----- | ----------- |
| АДР0  | ДЛИНА       |
| АДР1  | СИМВ2 СИМВ1 |
| АДР2  | СИМВ4 СИМВ3 |
| ...   | ...         |

где **ДЛИНА** — это **16-разрядное слово**, в котором значащими являются **8 младших бит**.

5. Ввод строки начинается со ввода **количества символов (1 байт)** и должен завершаться после ввода необходимого количества символов.

# Доп
